## 3. Dataset audit script (12:12)

**Files:** `scripts/audit_dataset.py`
**Context:** Checking the detection dataset before building splits. Written via a Bash heredoc, so the capture hook did not see it.

### Before
Did not exist. Nothing checked `dataset/manifest.jsonl` against the files on disk.

### Problem
The manifest had about 1,290 rows and the folders held about 1,400 files, with no check that they agreed. The part-3 run had also stopped partway, and nothing showed which pairs were missing per generator.

### Solution
A script that, for every `ok` fake in the manifest, checks the file exists, the sha256 matches and the real counterpart exists. It also lists files on disk that are not in the manifest, prints a per-generator count for part 1 (p) and part 3 (q), and lists pairs without an `ok` fake. It exits non-zero on any problem.

### Result
First run: 0 problems, but it showed the q run was incomplete (reswapper 32/50, ghost 0/50, inswapper 0/50). After the run was resumed: 0 problems, 1392 usable fakes. The only gaps are 4 q pairs each for faceswap-dlib-2d and -3d (q001, q016, q024, q033 and one more), which failed during generation.

## 4. Train/val/test split script and splits file (12:12)

**Files:** `scripts/make_splits.py`, `dataset/splits.json`
**Context:** Preparing the dataset for detector training. Written via a Bash heredoc.

### Before
Did not exist. There was no agreed train/val/test assignment.

### Problem
Without a fixed split, anyone training a detector could put the same pair's outputs from several generators in both train and test, which inflates results.

### Solution
Split by `pair_id` (70/15/15, seed 0), so every generator's output for one pair and that pair's real target land in the same split. A real image used by pairs in several splits goes to the highest-priority split (test over val over train). Two generators, `facefusion-uniface_256` and `faceswap-dlib-3d`, are listed as `heldout_generators` for leave-generator-out evaluation. Known limit: a train fake can share a target image or face id with a test pair.

### Result
Final run: train 976 fakes / 70 reals, val 210 / 15, test 206 / 15. The splits were first written while ghost was still running, then regenerated after it finished.
